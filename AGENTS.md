# gamma principles

henry's binding rules:

- "For any other tools that you think could be good in a web surface, use the same shape: API in gamma itself, not a tool specifically added into a harness for that specific purpose."
- "I don't want artifacts to be a native zeta tool, since zeta right now is mainly used in the TUI so having a render tool in the TUI would do nothing (bloat)"
- gamma uses fulcrum exactly as an npm user would: packed packages and public exports only.
